# Project Bolt Backend

This is a Node.js backend using Express and MongoDB for managing user and doctor details.

## Setup

1. Install dependencies:
   ```
npm install
   ```
2. Start MongoDB locally (default connection: mongodb://localhost:27017/projectbolt)
3. Run the server:
   ```
npm run dev
   ```

## API Endpoints

- Users: `/api/users`
- Doctors: `/api/doctors`

Supports CRUD operations for both users and doctors.

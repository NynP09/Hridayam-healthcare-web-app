Hridayam – Portable ECG Monitoring & Health Guidance System
A Smart, Portable, AI-Powered ECG Device for Early Cardiac Detection & Personalized Health Guidance

⭐ Overview
Hridayam is a next-generation portable 3-lead ECG device designed for continuous cardiac monitoring, early detection of abnormalities, and personalized health guidance.
This system combines IoT hardware, AI-powered ECG analysis, and patient-centric digital health features to deliver a complete, accessible cardiac care solution.

The software system processes ECG signals in real time, classifies them as Normal or Abnormal, generates auto-structured ECG reports, and offers lifestyle, diet, and exercise recommendations backed by medical guidelines.
Additionally, Hridayam includes virtual doctor consultations, enabling users to connect with healthcare professionals directly.

🎯 Key Features
🔹 1. Real-time ECG Signal Monitoring
3-lead ECG signal acquisition (portable device)
High-accuracy filtering & noise reduction
Real-time waveform visualization
RR-interval, HRV, heart rate calculation

🔹 2. AI-Based ECG Classification
Machine learning model trained on ECG datasets

Classifies signals as:
Normal
Abnormal (Arrhythmia, Irregularities)

Detects anomalies using:
R-peak detection
RR interval variance
Wave morphology analysis

🔹 3. Automatic ECG Report Generation
Generates downloadable reports (PDF format)
Includes:
ECG waveform snapshot
Heart rate
RR intervals
Abnormalities found
Doctor notes (optional)

🔹 4. Personalized Lifestyle Guidance
Based on abnormal patterns, the system suggests:
Diet modifications
Daily/weekly exercise plans
Stress management tips
Sleep recommendations

🔹 5. Virtual Doctor Appointment
Book online consultations
Share generated ECG report with doctor
Secure communication

🔹 6. Patient Dashboard
View history of ECG scans
Weekly/monthly health insights
Trend analysis
